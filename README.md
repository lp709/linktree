# Linktree | Leandro Jesus (LP)

Um agregador de links pessoal moderno, responsivo e minimalista estilo **Linktree**, desenvolvido para reunir perfis profissionais, redes sociais e tecnologias de estudo em uma única página elegante.

🔗 **Acesse online:** [https://lp709.github.io/linktree/](https://lp709.github.io/linktree/)

---

## 📸 Demonstração

O projeto foi construído focado em uma experiência limpa e fluida em qualquer dispositivo (Desktop, Tablet e Mobile).

---

## Funcionalidades

- **Design Responsivo:** Adaptado para celulares e telas maiores com cartões centralizados e sombras suaves.
- **Efeitos Hover Suaves:** Transições suaves de cores e bordas sem quebra de layout (*Zero Layout Shift*).
- **Troca Interativa de Imagem:** Clique na foto de perfil para alternar dinamicamente entre as imagens!
- **Rodapé Dinâmico:** Ano atualizado automaticamente via JavaScript para manter o copyright sempre em dia.
- **Boas Práticas e Segurança:** Tags semânticas em HTML5 e links com `target="_blank"` e `rel="noopener noreferrer"`.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da página, metadados Open Graph e acessibilidade.
- **CSS3:** Estilização moderna com Flexbox, transições, variáveis, suporte a `:hover` e `scrollbar-gutter`.
- **JavaScript (Vanilla):** Manipulação do DOM para interatividade da foto de perfil e injeção do ano atual no rodapé.
- **Font Awesome:** Ícones vetoriais para redes sociais e portfólio.

## 🚀 Como Executar Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/lp709/linktree.git
   ```

2. **Entre na pasta do projeto:**
   ```bash
   cd linktree
   ```

3. **Abra o projeto:**
   - Basta abrir o arquivo `index.html` em qualquer navegador;
   - Ou utilize a extensão **Live Server** no VS Code.
